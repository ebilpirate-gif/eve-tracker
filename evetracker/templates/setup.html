2. Connect your EVE application

CCP requires each tool like this to have its own "application" so you can log in with EVE Online. It's free and takes a couple of minutes.

  1. Open developers.eveonline.com/applications (opens in a new tab), log in with your EVE account, and create a new application.
  2. Give it any name and description, e.g. My EVE Tracker.
  3. Under Connection type, choose Authentication & API Access.
  4. Add these permissions (scopes). All are read-only; the app can never move items or ISK.

    If the site lets you search the scope list, type each name in. If it accepts a pasted list, .

  5. Set the Callback URL to:
    {{ suggested_callback }}

    This is the address you're using right now. Keep using this same address to open the app, because EVE login always comes back here. Give the Pi a fixed IP in your router (a "DHCP reservation") so it doesn't change.

  6. Create the application, then open its details and copy the Client ID and Secret Key into the form below.
